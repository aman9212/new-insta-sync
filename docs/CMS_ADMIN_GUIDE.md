# CreatorX Website Builder Admin Guide

Welcome to the **CreatorX No-Code Website Builder & CMS**. This guide provides an overview of how to manage your website from the Admin Panel.

---

## Accessing the Website Builder
1. Log in to the CreatorX Admin Panel with an administrator account.
2. Click **Website Builder** in the left sidebar navigation (`/admin/website-builder`).

---

## Key Modules

### 1. Dashboard Module
View high-level content statistics (published pages, blog posts, active announcements, and media assets) and quick actions.

### 2. Homepage & Hero Builder
- Edit main hero titles, subtitles, badge text, and descriptions.
- Set primary and secondary CTA button labels and URLs.
- Update hero statistics counters and floating cards.

### 3. Navbar & Footer Builders
- Customize logo text, target URLs, and sticky/glass transparency toggles.
- Add or reorder navigation links and sub-menus.
- Edit company description, office address, phone, email, and newsletter titles.

### 4. Dynamic Page Builder
- Create custom pages with unique slugs (`/p/:slug`).
- Set page statuses (`Draft`, `Scheduled`, `Published`, `Archived`).

### 5. Blog CMS Suite
- Create and edit blog articles with rich HTML content.
- Upload featured images, assign categories, author tags, and view article view counts.

### 6. Media Library
- Upload images, videos, SVGs, icons, and document assets.
- Search by asset name or tags and copy asset URLs in one click.

### 7. Announcements Manager
- Deploy top header banners, bottom-right toast notifications, or popups.
- Set custom banner colors, call-to-action links, and toggle live visibility.

### 8. SEO & Custom Code
- Configure default meta titles, descriptions, Open Graph social images, and canonical URLs.
- Safely inject Google Analytics 4, GTM, Meta Pixel, custom CSS, or JS scripts into `<head>` or `<body>`.

### 9. Maintenance Mode Engine
- Toggle site-wide maintenance mode when deploying updates.
- Set a custom countdown timer and whitelist admin access.
