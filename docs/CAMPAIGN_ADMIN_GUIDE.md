# Admin Guide: Campaign Management System

## Navigation Overview
Access the Campaign Management suite via the Admin Sidebar by navigating to **Campaign Management** (`/admin/campaigns`).

---

## Key Administrative Workflows

### 1. Managing Campaign Lifecycles
- Navigate through status sub-views: **Drafts**, **Scheduled**, **Pending Approval**, **Active**, **Paused**, **Completed**, **Expired**, and **Archived**.
- Use Quick Action buttons in the table to Activate, Pause, Duplicate, or Delete campaigns instantly.

### 2. Creating & Customizing Campaigns
- Click **+ Create Campaign** to launch the multi-column Campaign Builder.
- Configure Name, Slug, Description, Platforms (YouTube, TikTok, Instagram, X, Twitch, etc.), Total Budget, Daily Caps, and CPM Rates.
- Rules, targeting, and assets are updated dynamically without hardcoded values.

### 3. Campaign Templates Engine
- Apply pre-configured campaign blueprints (e.g. *Viral TikTok Clipping Blitz*, *YouTube Music Sound Drop*).
- Export template configs as JSON or import custom JSON payloads.

### 4. Verification & Anti-Fraud Rules
- Set automated thresholds for video publicity, original content verification, min retention %, min views, and AI spam flags.

### 5. Reports & Exports
- Under the **Reports** tab, download formatted CSV or JSON audit reports for Summaries, Creator Earnings, Finance, and Fraud Verifications.
